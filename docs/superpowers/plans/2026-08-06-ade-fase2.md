# Fase 2 — SPA Completa do Blueprint (ADE) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar a SPA React (workspace de runs + canvas DAG + console + time-travel/HITL/custos/MCP UIs) que consome o backend ADE da Fase 1, empacotada como `loopforge-ade` e servida por `lf serve`.

**Architecture:** Frontend React 19 + Vite (Rolldown) + Tailwind v4 em `web/loopforge-ade/frontend/`, com React Flow v12 (canvas DAG kanban/grafo), Zustand (estado de UI/runs + undo/redo), TanStack Query (server-state REST) e camada única WS (`shared/lib/ws.ts`) que mapeia os eventos reais do backend. Backend toca-se **apenas** no mínimo: mount StaticFiles da SPA em `/app` + CORS restrito em `create_app`. Sem router (abas de runs substituem navegação por URL no V1). Demo mock 1-clique (UX16) gera run sintética local sem backend — base do QA E2E.

**Tech Stack:** React 19 · Vite (Rolldown, como `web/quocient`: `"vite": "npm:rolldown-vite@7.1.12"`) · Tailwind CSS v4 · @xyflow/react v12 · Zustand v5 · @tanstack/react-query v5 · Vitest · Playwright · Python 3.12 (pytest p/ mount) · setuptools (pyproject `loopforge-ade`).

## Global Constraints

- **Idioma:** strings da UI em **inglês** (E8); comentários de código e README em **português** (padrão do repo).
- **Tema:** dark-first único (E15/UX18), paleta sóbria Vercel/Linear (zinc/neutral + um acento por tipo de nó), sem glassmorphism (UX19).
- **Sem router no V1** (abas de runs substituem navegação por URL).
- **Estilo de código:** 2 espaços, aspas simples, UTF-8, `.editorconfig` (padrão dos projetos web do repo).
- **NÃO tocar** `src/lf/pipeline/task_dispatcher.py` nem `src/lf/pipeline/llm_factory.py` (fora de escopo). Backend mínimo: mount `/app` + CORS em `src/lf/api/app.py`.
- **Nomes reais do backend (validados 2026-08-06, NÃO inventar outros):**
  - WS: `GET /ws/streaming` e `/ws/runs/{run_id}` com `?token=`; msg inicial `{event:"connected", status, run_id}`; pings → responder `{"type":"pong"}`.
  - Envelope WS: `{event, task_id, timestamp, **payload}` (dispatcher) ou `{event, run_id, ...}` (app).
  - Eventos: `pipeline_started{idea,node}` · `node_execution{node,status:"completed",next_agent,attempt_count}` · `pipeline_finished{status,error}`/`{run_id,status,duration_seconds}` · `pipeline_failed` · `pipeline_error` · `pipeline_resumed{thread_id,resuming_from_node}` · `human_decision_expired{node,timeout_seconds,run_status}` · `run_created{run_id,idea,status}` · `run_updated{run_id,status,current_node}` · `human_decision_submitted{run_id,gate_node,action,feedback_category,feedback_message,user}`.
  - REST: `POST /api/runs` (cria+dispara em background) · `GET /api/runs?skip&limit → {items,total}` · `GET /api/runs/{id}` · `POST /api/runs/{id}/resume` · `POST /api/runs/{id}/decide` · `GET /api/runs/{id}/decisions` · `GET/PATCH /api/v1/config` · `GET /api/v1/trajectories/{thread_id}/checkpoints` · `GET /api/v1/trajectories/{thread_id}/checkpoints/{checkpoint_id} → {thread_id, checkpoint_id, state: channel_values}` · `GET /api/v1/mcp/servers` · `GET /api/v1/mcp/servers/{name}/tools` · `GET /api/v1/providers/ollama/models`.
  - Envelope REST: respostas Pydantic diretas (sem `{success,...}`). Erros: `detail` padrão FastAPI.
  - `AdeConfig`: `budget.max_usd` · `mcp_servers[{name,command,args,tools_allowlist,enabled}]` · `providers{primary, ollama_base_url}` · `hitl.timeout_seconds`.
- **Gaps a respeitar:** token-streaming por nó NÃO existe (console mostra eventos reais + `run.logs`); export de trajectory é envelope vazio; time-travel endereçado por `thread_id`; `POST /api/runs` não aceita thread_id/checkpoint.
- **Auth REST (verificar na Task 3):** o smoke da Fase 1 mostrou que `lf serve` pode exigir header `X-API-Key` (extraído do log). O api client deve suportar `VITE_API_KEY` opcional → header `X-API-Key`. WS usa `?token=`.

- [ ] **Step 4: Implementar `types.ts` e `api.ts`**

`api.ts` (estrutura real):
```ts
import type { AdeConfig, Checkpoint, DecisionRecord, McpServer, McpTool, Run, RunListResponse } from './types'

const BASE = (import.meta.env.VITE_API_BASE as string | undefined) ?? '/api'
const API_KEY = import.meta.env.VITE_API_KEY as string | undefined

export class ApiError extends Error {
  constructor(public status: number, public detail: unknown) {
    super(`API ${status}: ${JSON.stringify(detail)}`)
  }
}

export async function apiFetch<T>(path: string, init: RequestInit = {}): Promise<T> {
  const headers: Record<string, string> = { ...(init.headers as Record<string, string> | undefined) }
  if (init.body) headers['Content-Type'] = 'application/json'
  if (API_KEY) headers['X-API-Key'] = API_KEY
  const res = await fetch(`${BASE}${path}`, { ...init, headers })
  if (!res.ok) {
    let detail: unknown = null
    try { detail = (await res.json()).detail } catch { /* ignore */ }
    throw new ApiError(res.status, detail)
  }
  return res.json() as Promise<T>
}

export const listRuns = (skip = 0, limit = 50) => apiFetch<RunListResponse>(`/runs?skip=${skip}&limit=${limit}`)
export const getRun = (id: string) => apiFetch<Run>(`/runs/${id}`)
export const createRun = (idea: string) => apiFetch<Run>('/runs', { method: 'POST', body: JSON.stringify({ idea }) })
export const resumeRun = (id: string) => apiFetch<Run>(`/runs/${id}/resume`, { method: 'POST' })
export const getDecisions = (id: string) => apiFetch<DecisionRecord[]>(`/runs/${id}/decisions`)
export const decideRun = (id: string, body: Record<string, unknown>) => apiFetch<Run>(`/runs/${id}/decide`, { method: 'POST', body: JSON.stringify(body) })
export const getConfig = () => apiFetch<AdeConfig>('/v1/config')
export const patchConfig = (partial: Record<string, unknown>) => apiFetch<AdeConfig>('/v1/config', { method: 'PATCH', body: JSON.stringify(partial) })
export const listMcpServers = () => apiFetch<McpServer[]>('/v1/mcp/servers')
```

```ts
import type { NodeType } from './types'

export interface WsEventBase { event: string; task_id?: string; timestamp?: number; [k: string]: unknown }
export interface WsEventNodeExecution extends WsEventBase { event: 'node_execution'; payload: { node: NodeType; status: 'completed'; next_agent?: string; attempt_count?: number } }
export interface WsEventPipelineStarted extends WsEventBase { event: 'pipeline_started'; payload: { idea: string; node: string } }
export interface WsEventGeneric extends WsEventBase { event: 'run_created' | 'run_updated' | 'pipeline_finished' | 'pipeline_failed' | 'pipeline_error' | 'pipeline_resumed' | 'human_decision_expired' | 'human_decision_submitted' }
export type WsEvent = WsEventNodeExecution | WsEventPipelineStarted | WsEventGeneric

const KNOWN = new Set(['pipeline_started','node_execution','pipeline_finished','pipeline_failed','pipeline_error','pipeline_resumed','human_decision_expired','human_decision_submitted','run_created','run_updated'])

export function normalizeWsEvent(raw: unknown): WsEvent | null {
  if (typeof raw !== 'object' || raw === null) return null
  const r = raw as Record<string, unknown>
  if (typeof r.event !== 'string' || !KNOWN.has(r.event)) return null
  return r as unknown as WsEvent
}

export interface WsClientOpts {
  url: string
  token?: string
  onEvent: (e: WsEvent) => void
  onStatus?: (s: 'connecting' | 'open' | 'closed' | 'error') => void
  backoffMs?: number
}

export function createWsClient(opts: WsClientOpts) {
  const backoffBase = opts.backoffMs ?? 1000
  let ws: WebSocket | null = null
  let closedByUs = false
  let timer: ReturnType<typeof setTimeout> | null = null
  let attempt = 0

  const connect = () => {
    closedByUs = false
    const url = opts.token ? `${opts.url}${opts.url.includes('?') ? '&' : '?'}token=${encodeURIComponent(opts.token)}` : opts.url
    opts.onStatus?.('connecting')
    ws = new WebSocket(url)
    ws.onopen = () => { attempt = 0; opts.onStatus?.('open') }
    ws.onmessage = (m) => {
      try {
        const data = JSON.parse(String(m.data))
        if (data?.type === 'ping') { ws?.send(JSON.stringify({ type: 'pong' })); return }
        const ev = normalizeWsEvent(data)
        if (ev) opts.onEvent(ev)
      } catch { /* frame não-JSON ignorado */ }
    }
    ws.onclose = () => {
      opts.onStatus?.('closed')
      if (closedByUs) return
      const delay = Math.min(backoffBase * 2 ** attempt, 10_000)
      attempt += 1
      timer = setTimeout(connect, delay)
    }
    ws.onerror = () => opts.onStatus?.('error')
  }

  const disconnect = () => {
    closedByUs = true
    if (timer) clearTimeout(timer)
    ws?.close()
    ws = null
  }

  return { connect, disconnect }
}
```

```ts
  lastEventAt: null,
  connect: (url, token) => {
```
